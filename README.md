# FCL v1
## Faltu Command Line v1. It is VERY faltu.

### How To Use:
#### 2 Methods:

##### You can either download the linked binary given here on Linux and run it.
##### Or you can download the assembly source, assemble and link it into a binary:
```
nasm -f elf64 fcl.asm -o fcl.o    # assemble it
ld fcl.o -o fcl                   # link it
./fcl                             # run it
```

#### Commands (very faltu, only 3 commands...):

##### ```helloworld```
Prints "Hello World!" to the terminal
##### ```info```
Displays some info about the FCL
##### ```exit```
Exits the FCL
